# 城市摆拍 beta 0.7.12 ·

适用于“开源城市 · 时空社区”（`https://mwsk.sensetime-inc.com/`）三维场景的纯本地机位工具。


## 在 Edge 或 Chrome 中使用

1. 打开 `edge://extensions` 或 `chrome://extensions`，开启“开发人员模式”。
2. 选择“加载解压缩的扩展程序”，选择本文件夹。
3. 打开并登录 `https://mwsk.sensetime-inc.com/`，进入显示三维城市的页面。
4. 等待“城市摆拍 beta”面板显示“场景已就绪”。
5. 点击“点选中心”，再点击场景中的位置；随后设置高度、朝向、机位角度和镜头视角。
6. “获取当前视图机位”可读取当前画面参数；保存和分享时会保留镜头视角。
7. 模型在部分低机位或远离中心的位置消失时，可在“显示设置”中打开“修复模型消失 BUG”。
8.分享链接中的机位与旋转中心经过自动加密编码；持有链接并安装扩展的人仍可还原机位。

## 日月规划

- 日期和精确到秒的时间按北京时间 UTC+8 计算，与电脑所在时区无关。
- 显示太阳/月亮方位、仰角、日出日落、月升月落及月面照明比例。
- 支持分钟滑块、播放一天、显示或清除轨迹。
